##  O que está sendo estudado

Marque os tópicos conforme avançar no curso (edite esta lista de acordo com as aulas reais):

-  Estrutura básica de um documento HTML (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
-  Títulos, parágrafos e formatação de texto
-  Links e navegação entre páginas
-  Imagens, áudio e vídeo
-  Listas ordenadas e não ordenadas
-  Tabelas
-  Formulários e campos de entrada
-  Tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
-  Boas práticas e acessibilidade

##  Como visualizar os exercícios

Não é preciso instalar nada.

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
   ```
2. Entre na pasta da aula desejada.
3. Abra o arquivo `index.html` no navegador (dois cliques ou clique direito › _Abrir com_).

Para uma experiência melhor, use a extensão **Live Server** do VS Code, que atualiza a página a cada alteração salva.
